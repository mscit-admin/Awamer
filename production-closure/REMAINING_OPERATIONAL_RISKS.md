# Remaining Operational Risks

None of these is an exploitable Critical or High vulnerability, and none invalidates a security boundary. They are verification gaps, hardening opportunities, or accepted dependency risks.

| ID | Severity | Risk | Why open | Action / owner |
|---|---|---|---|---|
| **OR-01** | **Blocking operational condition** | The **final production images were not built** here (Alpine mirror denied by the sandbox network policy). All application layers were verified, in the real base image under the real runtime restrictions, but the Alpine runtime packages (`tini`, `wget`, `iputils`, `traceroute`; `openvpn`, `iproute2`, `iptables`) and the image as a whole were not. | Environment | Build both images from commit `4e5d4bd` (CI `images` job or the target host). Record the digests; `docker compose up` with a throwaway `.env.production`; run `backend/scripts/smoke-production.mjs` (60 checks); confirm `/api/v1/version` reports the commit. **Before serving traffic.** |
| **OR-02** | Operational | **Upgrading an existing deployment:** the flaws closed by the security closure existed in previously deployed builds | Inherited | Run the post-upgrade compromise review (security-final `PRODUCTION_ACCEPTANCE.md` C-7): SMTP settings, VPN-server ciphers, stored `.ovpn` profiles (now-denied directives will refuse to launch), admin resets of super_admins; rotate `VPN_HELPER_SECRET` and DB passwords if in doubt |
| **OR-03** | Operational | Audit writes remain **fail-open** by design (availability for containment actions) | Design decision | Alert on `audit_write_failures_total > 0` per interval (see `PRODUCTION_CONFIGURATION.md`) |
| **OR-04** | Low (hardening) | vpn-helper root filesystem is **not** read-only (iptables lock file and OpenVPN executing `verify.sh` need a validated tmpfs layout) | Needs a real image to test | Add `read_only: true` + tmpfs (`/run` excluding the IPC volume, `/var/lib/awamer/vpn-runtime:exec,mode=0700`, `/tmp`) once images can be built; re-run the VPN workflow |
| **OR-05** | Medium (architectural) | vpn-helper uses the **host** network namespace; admin-supplied client profiles can add specific host routes (default-route takeover is blocked) | Required for dynamic server ports / reaching customer networks | Per-session network namespaces; admin-approved route prefixes |
| **OR-06** | Low | russh 0.63 depends on **prerelease** crypto crates (`ssh-key 0.7.0-rc.11`, `rsa 0.10.0-rc.18`); `rsa` carries RUSTSEC-2023-0071 (Marvin, CVSS 5.9, no fix anywhere) | Upstream | Track stable releases; prefer Ed25519 client keys |
| **OR-07** | Low | `node-forge` advisory (verify path, unused) with no fix; `@fastify/swagger-ui` 5 → `@fastify/static` advisory (never loaded in production) | No fix / major upgrade | Migrate the PKI to `node:crypto` or `@peculiar/x509`; upgrade swagger-ui |
| **OR-08** | Low | Production guards key off `APP_ENV` (default `development`); the dev compose runs the production image with `APP_ENV=development`, so a `NODE_ENV`/`APP_ENV` mismatch cannot simply be refused | Would break local dev | The production compose sets `APP_ENV=production` explicitly; keep it in the compose contract |
| **OR-09** | Low (functional) | SSH gateway reports `connected` on SSH-ready, **before** the shell channel and its stdin handler exist: keystrokes in the first milliseconds are dropped | Found by the smoke test; not security-relevant; behaviour change deferred | Send `connected` after `conn.shell()` succeeds, or buffer early input |
| **OR-10** | Operational | The integration test suite re-provisions the cluster-wide `awamer_*` roles | Test design | **Never run tests against a cluster that hosts a real Awamer database** (CI uses an ephemeral service) |
| **OR-11** | Low | Frontend dev toolchain advisories (vitest critical, vite high; dev only) and react-router v6 moderate (not reachable) | Major upgrades | Toolchain upgrade (vite 8, vitest 5, react-router 7) |
| **OR-12** | Low | VPN tunnel data plane, Tauri bundle and real-browser WebSocket terminals were not exercised end to end here | Environment | Covered by OR-01's on-target smoke plus a manual VPN connect |
| **OR-13** | Low | Items carried from `security-final/REMAINING_RISKS.md` not addressed in this phase: foreign-reference oracle (R-07), audit `company_id` / IP columns (R-08), readonly notes (R-09), global namespaces (R-10), IPv6 `/64` rate-limit grouping (R-13), WebSocket back-pressure (R-15), account-state enumeration (R-16) | Out of this phase's scope (small blast radius) | Scheduled backlog |
