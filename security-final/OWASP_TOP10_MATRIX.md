# OWASP Top 10 (2021) — Final Matrix

**Status reflects the remediated code** on branch `claude/determined-fermat-zf9h5p`. The
"Baseline" column shows what the same assessment found on commit `8a8fb5b` before the fixes.

Status values:
- **PASS:** evidenced controls, with no confirmed exploitable issue left.
- **PARTIAL:** controls work, but medium or low residual risks remain (see `REMAINING_RISKS.md`).
- **FAIL / NOT VERIFIED:** as named.

| OWASP Category | Baseline | Final status | Evidence | Remaining Risk |
|---|---|---|---|---|
| **A01 Broken Access Control** | FAIL | **PASS** | Server-side RBAC with a live DB role on every request. Grant ceiling plus the **new target ceiling** (FINAL-CEIL-001/003). Instance settings now need `settings:manage` (FINAL-INST-001). Tenant scoping is in SQL (tenantIsolation/NullScope/Shares itests). WebSocket permission is checked at open and revalidated; tunnels and SFTP are now revocable. Baseline failures: admin → super_admin takeover, helpdesk demoting its admin, cross-tenant SMTP | R-07 foreign-reference oracle, R-09 readonly notes, R-10 global namespaces (all Low) |
| **A02 Cryptographic Failures** | PARTIAL | **PASS** | Argon2id (m=64 MiB, t=3, p=4). AES-256-GCM with a random 96-bit IV and **full 128-bit tags now enforced** (SECRETBOX-TAG-001, BACKUP-KDF-003). 32-byte key required in production. HS256 pinned. CSPRNG for reset tokens, VNC tickets and **SFTP handles (was Math.random)**. TOTP secrets encrypted, fail-closed. Backup KDF parameters pinned. No MD5/SHA1 password hashing, ECB or static IV found | No key-rotation / key-ID support (Info) |
| **A03 Injection** | FAIL | **PASS** | All SQL is parameterised; `${}` in SQL is limited to constant column lists or fragments. Process spawning uses argument arrays with `shell:false`. **VPN-server config injection fixed** (VPN-CFG-001/002). **Client `.ovpn` file/control directives blocked** (OVPN-FILE-001). Email templates are HTML-escaped. pino JSON logs | R-03 (route influence on the host namespace; Medium, architectural) |
| **A04 Insecure Design** | FAIL | **PARTIAL** | Fixed design flaws: MFA challenge token was a session token; instance-wide settings were tenant-admin writable; MFA failure counter was reset between factors; logout-all left sessions alive; raw TCP relays had no destination policy | R-02 DB superuser, R-03 helper host-network design (Medium) |
