# OWASP API Security Top 10 (2023) — Final Matrix

| API Risk | Final status | Evidence | Remaining Risk |
|---|---|---|---|
| **API1 Broken Object Level Authorization (BOLA)** | **PASS** | Every object-ID endpoint is scoped by owner (`user_id`), company, or an explicit tenant check before use. Inventory and cross-tenant outcomes are in `TENANT_ISOLATION_TESTS.md`. Executed suites: tenantIsolation, tenantShares, tenantNullScope, moveRbac, rbacRoles | R-07 foreign-reference existence oracle (Low) |
| **API2 Broken Authentication** | **PASS** (was FAIL) | MFA challenge token now typed and unusable as a session (FINAL-MFA-001). Per-account MFA lockout; TOTP replay protection. Atomic refresh rotation with reuse detection. HS256 pinned, typed tokens, `iss`. Live account-state and `auth_version` check on every REST/WS request. Login/MFA/refresh/reset/step-up rate-limited | R-16, R-20 (Low) |
| **API3 Broken Object Property Level Authorization** | **PASS** | zod schemas with field allow-lists. `/users/me` accepts only `full_name`/`email`; zod drops unknown keys, so role/company/is_active cannot be mass-assigned. Admin PATCH lists its fields explicitly and is now target-ceiling-checked. Responses use views (`userView`, `toVpnProfilePublic`, `toVpnServerPublic`, SMTP `has_password`); secrets only via audited reveal endpoints | — |
| **API4 Unrestricted Resource Consumption** | **PARTIAL** | Global 120/min plus login-grade limits (extended to reset/step-up). 100 KB default body limit with explicit per-route caps. **Backup scrypt-parameter DoS fixed.** **WebSocket frames capped at 2 MiB** (was 100 MiB, pre-auth). VNC tickets 30 s single-use. AI input/token caps | R-13 IPv6 `/64` and per-user limits, R-15 WS back-pressure / per-user session cap (Low) |
| **API5 Broken Function Level Authorization** | **PASS** (was FAIL) | `requirePermission` / `requireRole` / `can()` on every privileged route and gateway. **Instance settings moved to `settings:manage`** (FINAL-INST-001/003). Target ceiling on user administration (FINAL-CEIL-001/003). Frontend gating is cosmetic only | Role-name gates on `/admin/*` (fail-closed; see the RBAC matrix observations) |
| **API6 Unrestricted Access to Sensitive Business Flows** | **PASS** | Password reset: rate-limited, single-use hashed tokens, trusted base URL only, sessions revoked on reset. Credential/VPN reveal: permission-gated and audited. Admin password/MFA resets: ceiling-checked and audited | R-16 reset timing (Low) |
| **API7 Server Side Request Forgery** | **PASS** (was FAIL) | Remote-session destination policy (REMOTE-DEST-001..006). AI safeFetch (safeFetch.test). Diagnostics CIDR policy (networkPolicy.test, netScope/netCidr itests). SMTP host now changeable only by super_admin | R-18 (Info) |
| **API8 Security Misconfiguration** | **PARTIAL** | Fail-closed production config; strict CORS list with credentials; helmet plus nginx headers; generic 500 handler (no stack/SQL to clients); Swagger off and not proxied | R-11, R-12, R-17 (Low) |
| **API9 Improper Inventory Management** | **PARTIAL** | OpenAPI exists (dev only). Route inventory in `RBAC_AUTHORIZATION_MATRIX.md` / `TENANT_ISOLATION_TESTS.md`. **Versions are inconsistent** and there is no version endpoint | R-04 (Medium) |
| **API10 Unsafe Consumption of APIs** | **PASS** | AI provider responses size-capped (5 MiB) with timeouts; https only; revalidated redirects. VPN-helper IPC authenticated (HMAC, nonce, skew) and inputs re-validated on the privileged side (**cipher allowlist and `.ovpn` checks re-run in the helper**). SMTP via nodemailer 10.0.13 | R-18 (Info) |
